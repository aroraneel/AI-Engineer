# Phase 1 — Data & Statistics Foundations

**Days 1–10** &nbsp;·&nbsp; Part of the [AI Engineer Roadmap](../README.md)

NumPy, Pandas, reading data from real-world sources, visualization, and the
core descriptive/inferential statistics that every later phase builds on.

## Days in This Phase

| Day | Topic |
|---|---|
| [Day 1](./Day-01-Numpy-Basics) | NumPy fundamentals: arrays, indexing, broadcasting, vectorized operations |
| [Day 2](./Day-02-Pandas-Basics) | Pandas Series & DataFrame; core data manipulation |
| [Day 3](./Day-03-Reading-Data) | Reading data from multiple sources: CSV, JSON, SQL, REST APIs |
| [Day 4](./Day-04-Matplotlib-Basics) | Data visualization with Matplotlib: line, bar, scatter, subplots |

| [Day 9](./Day-09-Percentiles-IQR) | Histograms; percentiles & quartiles; the 5-number summary |
| [Day 10](./Day-10-Correlation-Covariance) | Correlation & covariance; spotting outliers |

## What This Phase Covers

By the end of this phase: comfortable manipulating data in NumPy and Pandas,
pulling data from any common source, building clear visualizations, and
using descriptive statistics (mean/median/mode, variance, std dev,
percentiles, correlation) to actually understand a dataset before doing
anything else with it.
