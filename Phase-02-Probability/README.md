# Phase 2 — Probability & Inference

**Days 11–20** &nbsp;·&nbsp; Part of the [AI Engineer Roadmap](../README.md)

Probability theory, the full family of distributions used across statistics
and ML, and the hypothesis-testing toolkit that underlies model evaluation,
A/B testing, and feature selection.

## What This Phase Covers

By the end of this phase: fluent in the core probability distributions
(Bernoulli, Binomial, Poisson, Normal, Uniform, Log-normal, Power law,
Pareto, Student's t) and when each one applies; comfortable running and
interpreting Z-tests, t-tests, chi-square tests, and ANOVA; understanding
what a p-value actually measures (and doesn't); building and interpreting
confidence intervals; and — the hardest and most valuable skill — knowing
how to choose the right statistical test for a given real-world question,
demonstrated end-to-end in the Day 20 capstone.
